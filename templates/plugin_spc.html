SPC Tools for Claude Code

Control charts, process capability, and Gage R&R — directly in your terminal. Powered by the Forge quality engineering engine. Free and open source.

/plugin install spc-tools

or from the Plugin tab in Claude Code

Skills

/spc-tools:control-chart

Create SPC control charts from your data with automatic out-of-control detection.

  • I-MR, X-bar/R, X-bar/S (variables)
  • p, c, u, np (attributes)
  • CUSUM, EWMA (small shift detection)
  • Nelson rules & Western Electric rules

/spc-tools:capability

Assess whether your process meets specification limits.

  • Cp, Cpk, Pp, Ppk indices
  • Sigma level, DPMO, yield
  • Bayesian capability with credible intervals
  • Capability histogram with spec overlay

/spc-tools:gage-rr

Validate your measurement system before making process decisions.

  • Crossed and nested study designs
  • Repeatability & reproducibility breakdown
  • Number of distinct categories (ndc)
  • AIAG acceptance criteria
